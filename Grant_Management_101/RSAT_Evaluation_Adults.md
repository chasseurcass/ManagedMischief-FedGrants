**ADULT RSAT PROGRAM EVALUATION CHECKLIST**

Use this checklist to determine whether a program meets RSAT statutory purpose, program brief expectations, and required treatment structure.

Mark each item:

- [ ]  Yes
- [ ]  No
- [ ]  Needs clarification

# **A. Program Identification and Structure**

A1. RSAT-funded program is clearly defined

- [ ]  Program track or unit is named
- [ ]  Eligibility criteria for RSAT participants is described
- [ ]  RSAT participants are tracked separately from general population

A2. Program type matches RSAT categories

- [ ]  Residential RSAT program
- [ ]  Jail-based RSAT program
- [ ]  Aftercare / community-based RSAT program

A3. Program duration meets RSAT expectations

- [ ]  Residential: approx. 6–12 months
- [ ]  Jail-based: approx. 3–6 months
- [ ]  Aftercare: approx. 6–12 months
- [ ]  Duration is clearly described in the application

# **B. Required Component 1: Substance Use Treatment**

This is non-negotiable. Every RSAT program must include real SUD treatment.

B1. Evidence-based treatment model identified

At least one is clearly described:

- [ ]  Cognitive Behavioral Therapy for SUD
- [ ]  Motivational Interviewing (MI)
- [ ]  Moral Reconation Therapy (MRT)
- [ ]  Relapse Prevention curriculum
- [ ]  Other named SUD model (with description)
- [ ]  MAT available or coordinated when clinically appropriate

B2. Qualified service delivery

- [ ]  Licensed or credentialed SUD provider(s) identified
- [ ]  Treatment dosage (frequency, format) described
- [ ]  Group and/or individual sessions clearly defined
- [ ]  Treatment is structured, scheduled, and documented

B3. Substance use monitoring

- [ ]  UA / other drug testing in place
- [ ]  Clear protocol for responding to positive tests
- [ ]  Treatment plan adjusts based on progress or relapse indicators

# **C. Required Component 2: Behavioral / Criminogenic Change**

RSAT is not only SUD treatment. It must also address behavior and criminogenic needs.

C1. Behavioral interventions identified

At least one is present:

- [ ]  Cognitive-behavioral groups (thinking/behavior change)
- [ ]  Trauma-informed therapy
- [ ]  Anger management or coping skills curriculum
- [ ]  Life skills or prosocial decision-making curriculum

C2. Behavioral work ties directly to SUD recovery

- [ ]  The application connects behavioral interventions to relapse prevention
- [ ]  Behavioral goals appear in treatment or case plans

# **D. Required Component 3: Aftercare / Continuity of Care**

All RSAT programs must prepare participants for release and maintain support.

D1. Reentry planning

- [ ]  Reentry planning begins before program completion
- [ ]  Aftercare plan created for each participant
- [ ]  Concrete linkage to community SUD treatment provider
- [ ]  Warm handoffs described when possible

D2. Community coordination

- [ ]  Identified community SUD provider(s)
- [ ]  Identified MH provider(s) if needed
- [ ]  Coordination with probation/parole described
- [ ]  Documentation of appointments, referrals, and follow-up

# **E. Required Component 4: Stability Supports (Wraparound)**

RSAT allows wraparound services only when connected to SUD recovery and relapse prevention.

E1. Housing stability

- [ ]  Housing status assessed before release
- [ ]  Housing plan included in aftercare
- [ ]  Linkage to sober living, transitional housing, shelters, or stable placements
- [ ]  Coordination with housing services outside of RSAT funds (RSAT can support coordination but not pay rent)

E2. Income / employment stability

- [ ]  Workforce development, training, or job placement partnerships
- [ ]  Employment is linked to relapse prevention and stability
- [ ]  RSAT funds cover only coordination, not employment stipends

E3. Social stability

- [ ]  Connections to peer support, mentors, prosocial community supports
- [ ]  Assistance accessing benefits (e.g., Medicaid), if appropriate

# **F. Case Management / Coordination (RSAT-Funded)**

Case management must support treatment. It cannot replace treatment.

Use this as a decision tree.

F1. Does RSAT fund case management?

- [ ]  Yes
- [ ]  No → Skip to Section G

F2. Is a full SUD treatment model present (Section B)?

- [ ]  Yes
- [ ]  No → Flag. RSAT cannot be case management alone.

F3. Case management tasks include (check all that apply):

- [ ]  Scheduling and coordinating SUD treatment
- [ ]  Monitoring attendance and following up on missed sessions
- [ ]  Coordinating MH treatment or trauma support
- [ ]  Assisting with reentry plan implementation
- [ ]  Connecting participants to stability supports (housing, employment)
- [ ]  Documenting all contacts and interventions

F4. Budget analysis

- [ ]  Case management is a supporting cost
- [ ]  Case management is a majority of RSAT costs
- [ ]  Case management is the core of the program (flag for review)

# **G. Performance Measures**

G1. SUD outcomes

- [ ]  Change in UA results over time tracked
- [ ]  Treatment completion rates tracked
- [ ]  Linkage to community SUD treatment tracked

G2. Justice outcomes

- [ ]  Recidivism tracked at regular intervals
- [ ]  Violations or sanctions tracked
- [ ]  New offenses tracked

G3. Reentry outcomes

- [ ]  Housing at exit
- [ ]  Employment at exit or enrollment in workforce services
- [ ]  Engagement with community providers

# **H. Pass / Needs-Work Snapshot**

H1. Treatment (Section B)

- [ ]  Fully present
- [ ]  Partially present
- [ ]  Not present

H2. Behavioral change component (Section C)

- [ ]  Fully present
- [ ]  Partially present
- [ ]  Not present

H3. Aftercare / reentry (Section D)

- [ ]  Fully present
- [ ]  Partially present
- [ ]  Not present

H4. Stability supports (Section E)

- [ ]  Fully present
- [ ]  Partially present
- [ ]  Not present

H5. Case management alignment (Section F)

- [ ]  Clearly supportive
- [ ]  Excessive or unclear
- [ ]  Dominant but unsupported by treatment (flag)
