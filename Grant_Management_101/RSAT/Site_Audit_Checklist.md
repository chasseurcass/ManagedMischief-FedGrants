# RSAT Site Audit Checklist for MAT Programs
Use this checklist to verify compliance with RSAT, MAT clinical standards, security requirements, and documentation expectations.  
Mark each item as:  
- Compliant (C)  
- Partially Compliant (PC)  
- Non-Compliant (NC)  
- Not Applicable (N/A)  

---

# 1. Administrative & Program Structure

## 1.1 Required Policies Present
- [ ] MAT Program Policy (overview and purpose)
- [ ] OUD Screening Policy
- [ ] Diagnostic Confirmation Policy
- [ ] Buprenorphine Induction Protocol
- [ ] Buprenorphine Maintenance Protocol
- [ ] Diversion Control Policy
- [ ] Release & Continuity-of-Care Policy
- [ ] Incident Reporting Policy
- [ ] Documentation Standards
- [ ] Pharmacy storage and inventory procedures
- [ ] Staff training policy covering MAT

## 1.2 Governance & Staffing
- [ ] Program has identified prescriber(s) for MOUD
- [ ] Nursing staff trained on induction and monitoring
- [ ] Counselor/MH provider trained on SUD-specific interventions
- [ ] Case manager assigned for release planning
- [ ] Security staff trained in diversion control
- [ ] Program has a designated MAT coordinator or point of contact

---

# 2. Screening & Diagnosis

## 2.1 Intake Screening
- [ ] Screening conducted within required timeframe (≤4 hours of booking)
- [ ] Standardized OUD questions used consistently
- [ ] Screening documentation present and complete
- [ ] Withdrawal symptoms assessed when appropriate
- [ ] Screen-positive individuals referred for diagnostic confirmation

## 2.2 OUD Diagnostic Confirmation
- [ ] DSM-5 criteria used
- [ ] Diagnosis documented clearly (mild/moderate/severe OUD)
- [ ] Clinical assessment signed by prescriber
- [ ] Documentation includes supporting symptoms/criteria
- [ ] Eligibility for induction or continuation determined and recorded

---

# 3. Medication Protocols & Induction

## 3.1 Medication Procurement & Storage
- [ ] Medications obtained through approved vendor or pharmacy
- [ ] Inventory system in place
- [ ] Storage meets security requirements (locked, limited access)
- [ ] Temperature control documented (if required)
- [ ] Daily counts performed and reconciled

## 3.2 Buprenorphine Induction
- [ ] COWS score documented before first dose
- [ ] Minimum COWS threshold followed (≥8 unless clinically justified)
- [ ] First dose documented with time, amount, staff initials
- [ ] Reassessment documented within 45–60 minutes
- [ ] Total Day 1 dose ≤12 mg unless justification present
- [ ] Patient consent documented
- [ ] Adverse reactions noted and addressed

---

# 4. Maintenance & Monitoring

## 4.1 Dosing & Administration
- [ ] Directly Observed Therapy used consistently
- [ ] Mouth checks performed and documented
- [ ] Daily dosing logs match medical record
- [ ] No unexplained dose omissions
- [ ] Dose changes documented with clinical reasoning

## 4.2 Clinical Monitoring
- [ ] Weekly prescriber or clinician check-ins (first month)
- [ ] Follow-up every 2–4 weeks thereafter
- [ ] Craving, withdrawal, and side effect monitoring documented
- [ ] Monthly urine drug screens completed and filed
- [ ] Missed UDS documented with reason

## 4.3 Counseling Integration
- [ ] SUD-specific counseling provided (not general MH groups)
- [ ] Counseling notes tie to SUD goals (triggers, relapse, coping skills)
- [ ] Frequency of counseling meets RSAT expectations
- [ ] Attendance tracked and reconciled

---

# 5. Diversion Control

## 5.1 Prevention Procedures
- [ ] Pre-dose mouth check documented
- [ ] Post-dose mouth check documented
- [ ] Tablets/films observed until dissolved
- [ ] Officers trained on S&S procedures related to MAT

## 5.2 Detection & Response
- [ ] Incident reports completed for suspected diversion
- [ ] Medication discrepancies investigated and resolved
- [ ] Diversion incidents reviewed by medical + security supervisors
- [ ] Participants reassessed clinically when diversion is suspected

---

# 6. Release & Continuity of Care

## 6.1 Transition Planning
- [ ] Release dates monitored and flagged early
- [ ] Warm handoff provider list available and current
- [ ] Appointments scheduled prior to release
- [ ] Release packet includes treatment summary and provider information

## 6.2 Medication Continuity
- [ ] 7–14 day prescription or supply provided (per policy)
- [ ] Documentation of release medication
- [ ] Participant educated on how to continue MAT after release

## 6.3 Data Tracking
- [ ] Follow-up attempts documented
- [ ] Linkage success tracked if allowed by local policy

---

# 7. Documentation Standards

## 7.1 Clinical Documentation
- [ ] Behavioral, objective language used
- [ ] SUD treatment plans updated at least every 30 days
- [ ] Progress notes align with treatment goals
- [ ] Dose adjustments include rationale
- [ ] Induction notes include COWS and timing

## 7.2 Medication Records
- [ ] Pharmacy log matches MAR (Medication Administration Record)
- [ ] Variances investigated and resolved
- [ ] Controlled substance logs maintained properly

---

# 8. Program Reporting & Compliance

## 8.1 RSAT Data Requirements
- [ ] Monthly/quarterly reporting submitted on time
- [ ] Data consistent with logs, UDS, and census
- [ ] MAT census accurately reported
- [ ] Required performance measures documented

## 8.2 Internal Quality Review
- [ ] Program conducts periodic internal audits
- [ ] Corrective actions documented
- [ ] Staff retraining performed after identified issues
