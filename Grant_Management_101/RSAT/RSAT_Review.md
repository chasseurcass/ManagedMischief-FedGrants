# Juvenile SUD Drivers & Drug-Use Situations

(AKA: the SUD-Specific Behavioral Domains DOJ implicitly expects treatment to target)**

If a program’s intervention **directly addresses items in these domains**, it counts as SUD treatment.
If it doesn’t, it is NOT SUD treatment.

## DOMAIN 1. **Internal Emotional Drivers**

These are emotional states that trigger use.

### SUD-specific issues:

- [ ] Using substances to manage anger
- [ ] Using substances to calm anxiety
- [ ] Using substances to cope with depression
- [ ] Using substances after trauma reminders
- [ ] Using substances to avoid emotional discomfort
- [ ] Using substances to feel numb or escape

### What treatment must do:

- [ ] Identify emotional triggers for drug use
- [ ] Teach alternative coping strategies
- [ ] Practice emotional regulation skills *specifically in place of using*


# DOMAIN 2. **Cognitive / Thinking Patterns**

Thoughts that support or justify substance use.

### SUD-specific thinking patterns:

- [ ] “It’s not a big deal, everyone smokes weed.”
- [ ] “I need it to sleep / calm down / focus.”
- [ ] “I can stop any time.”
- [ ] “I only use when I’m mad, so it’s not a problem.”
- [ ] “Probation won’t catch me.”
- [ ] “I won’t get addicted because I’m young.”

### What treatment must do:

- [ ] Identify thoughts tied to drug use
- [ ] Challenge beliefs that reinforce use
- [ ] Replace them with healthier cognitions
- [ ] Build refusal and decision-making skills


## DOMAIN 3. **Behavioral Triggers & Routines**

Specific actions or patterns that precede use.

### SUD-specific behaviors:

- [ ] Using after school
- [ ] Using before/after probation meetings
- [ ] Using when alone and bored
- [ ] Using when certain music, games, or routines cue it
- [ ] Using immediately after fights or discipline
- [ ] Using on weekends with no supervision

### Treatment must:

- [ ] Map the behavior chain leading to use
- [ ] Identify high-risk routines
- [ ] Build replacement behaviors
- [ ] Practice coping in these exact situations


## DOMAIN 4. **Peer Influence Dynamics**

Youth substance use is overwhelmingly social.

### SUD-specific peer drivers:

- [ ] Friends who use
- [ ] Friends who supply substances
- [ ] Peer pressure
- [ ] Using substances to fit in
- [ ] Gang-involved peers who normalize drug use
- [ ] Dating partners who use

### Treatment must:

- [ ] Identify high-risk peers
- [ ] Build peer refusal skills
- [ ] Set up monitoring/limits around peer contact
- [ ] Replace high-risk peer networks with pro-social ones

## DOMAIN 5. **Family & Home Environment**

Home conditions that allow or encourage use.

### SUD-specific family factors:

- [ ] Lack of supervision or inconsistent supervision
- [ ] Family conflict that triggers use
- [ ] Adults in the home who use substances
- [ ] Family norms that minimize substance use
- [ ] No structure/rules around curfew, internet, location

### Treatment must:

- [ ] Increase caregiver monitoring and supervision
- [ ] Improve communication about substance use
- [ ] Create rules and expectations around drug use
- [ ] Strengthen family support and consequences
- [ ] Ensure caregivers can identify relapse warning signs

**THIS is why family therapy is often *essential*, not “supportive.”**
Because these factors DRIVE the substance use.

## DOMAIN 6. **Psychiatric/Co-occurring Symptoms**

Symptoms that directly precipitate drug use.

### SUD-specific co-occurring issues:

- [ ] Trauma
- [ ] PTSD symptoms
- [ ] Depression
- [ ] Anxiety
- [ ] ADHD impulsivity
- [ ] Conduct disorder
- [ ] Emotional dysregulation

### Treatment must:

- [ ] Identify psychiatric triggers
- [ ] Teach coping skills *specifically relevant to drug use moments*
- [ ] Integrate SUD work into MH treatment (not separate)

## DOMAIN 7. **Motivation & Ambivalence**

Youth rarely want to stop using.

### SUD-specific motivational issues:

- [ ] Low motivation to reduce use
- [ ] Not seeing use as harmful
- [ ] Thinking they can hide use from probation
- [ ] Ambivalence about quitting
- [ ] Not linking drug use to consequences

### Treatment must:

- [ ] Use MI strategies to increase motivation to change
- [ ] Create clear change goals around substance use
- [ ] Elicit “change talk” specifically about reducing drugs

## DOMAIN 8. **Relapse Patterns**

Youth relapse for reasons adults often don’t.

### Juvenile relapse drivers:

- [ ] Getting in trouble at school
- [ ] Sports suspension or activity loss
- [ ] Relationship breakups
- [ ] Losing privileges at home
- [ ] Boredom
- [ ] Social media triggers
- [ ] Seasonal/holiday patterns
- [ ] Probation stress

### Treatment must:

- [ ] Create a relapse prevention plan
- [ ] Identify early warning signs
- [ ] Practice strategies for high-risk relapse situations

## DOMAIN 9. **Consequences & Accountability**

Youth often do not connect use with outcomes.

### SUD-specific accountability gaps:

- [ ] Minimal insight into legal or health consequences
- [ ] Not understanding probation requirements
- [ ] Believing they can “game” UA schedules
- [ ] Thinking vaping THC isn’t real use

### Treatment must:

- [ ] Build insight into consequences
- [ ] Link behaviors to probation/court outcomes
- [ ] Teach accountability for drug-related behaviors


## DOMAIN 10. **Skill Deficits**

Youth lack the skills needed to avoid use.

### SUD-specific skill deficits:

- [ ] Refusal skills
- [ ] Planning ahead to avoid high-risk situations
- [ ] Communicating needs to caregivers
- [ ] Managing cravings
- [ ] Problem-solving without substances
- [ ] Conflict resolution that doesn’t escalate into use

### Treatment must:

- [ ] Teach and practice these skills repeatedly
- [ ] Apply them to real drug-use situations, not hypotheticals
---


## If an RSAT applicant can show:

* They identify the youth’s drug-use situations (from the list above)
* They address AT LEAST 4–6 domains with structured intervention
* They provide SUD-specific skill-building
* They set SUD-specific goals
* They measure SUD outcomes

Then they are delivering juvenile SUD treatment.
